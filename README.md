# BMW Automotive Insights Hub 🚗📊

A modular, executive-grade sales analytics dashboard built with Python, Pandas, Seaborn, and integrated with the Model Context Protocol (MCP) for dynamic data querying and validation.

## 🚀 Key Features
•⁠  ⁠*Dynamic Data Generation:* Generates synthetic, realistic BMW sales datasets across multiple global regions and car models.
•⁠  ⁠*MCP Integration:* Implements Model Context Protocol tools for robust, query-driven data retrieval and structured error handling.
•⁠  ⁠*Executive Visualizations:* Side-by-side Matplotlib & Seaborn subplots providing clear regional performance and model-wise revenue insights.
•⁠  ⁠*Automated Summaries:* Generates instant markdown-based insights highlighting top and lowest performing categories.

## 🛠️ Tech Stack
•⁠  ⁠*Language:* Python
•⁠  ⁠*Data Manipulation:* Pandas, NumPy
•⁠  ⁠*Data Visualization:* Matplotlib, Seaborn
•⁠  ⁠*Architecture:* MCP Tools & Modular Functions
